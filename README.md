# Заощадження грошей

Повністю український трекер заощаджень. React 19, TypeScript, Vite/Vinext, Tailwind CSS, Lucide, Radix/shadcn та Recharts. Бізнес-дані зберігаються тільки в localStorage; база даних і платіжні сервіси не потрібні.

## Запуск

Потрібен Node.js 22.13+ та npm.

```sh
npm ci
npm run dev
```

Локальна адреса: http://127.0.0.1:5173/

```sh
npm run build
npm start
```

Продакшн-збірка використовує стандартне середовище Sites/Cloudflare для роздачі застосунку. Власний бекенд для даних не використовується.

## Структура

- `app/page.tsx` — сторінки огляду, статистики та налаштувань, керування станом.
- `components/savings/` — банки, форми, історія, графік, підтвердження.
- `lib/savings/model.ts` — типи, валідація, гроші, обчислення.
- `lib/savings/storage.ts` — ізольований адаптер зберігання.
- `tests/model.test.ts` — регресійні тести грошових операцій.

## Правила даних

Суми — цілі копійки/центи. Баланс обчислюється з операцій; початкова сума — окреме поповнення. Кожна операція й ціль обмежена 100 000 000 одиниць валюти; до 1 000 банок і 20 000 операцій у файлі. Сукупні обчислення залишаються в межах безпечних цілих JavaScript.

Підсумок балансу та цілей включає активні банки обраної валюти. Кількість банок включає всі активні валюти. Статистика й місячний приріст включають також архівні банки. Сортування за сумою групує банки за валютою. Курсів валют немає.

Видалення поповнення, що зробило б баланс від’ємним, блокується. Архівування зберігає всю історію. Зняття, видалення та заміна імпортом потребують підтвердження.

Імпорт JSON перевіряє структуру, унікальність ID, посилання операцій, дати та невід’ємні залишки до заміни. Експортуйте резервні копії перед очищенням браузера: дані не синхронізуються між пристроями або різними адресами сайту.

## Перевірки

```sh
npx tsc --noEmit
node scripts/test-savings.mjs
npm run build
```

У браузері перевірено створення, поповнення, блокування перевищення балансу, зняття з підтвердженням, видалення/перерахунок, збереження після оновлення, валютні підсумки та макети 390px і 1440px. Прогноз має орієнтовний характер і використовує середній чистий темп накопичення від дати створення (щонайменше 30 днів).
